# 台账：跨批次累积

台账是**追加式**的：每次抓完追加一次，历史批次才接得上。

## 什么时候追加

每次 `top` / `keyword` / `tier` 产出新 JSON 之后：

```bash
node run.mjs ledger dy_output/top3_xxx.json
node run.mjs ledger dy_output/a.json dy_output/b.json     # 一次追加多个
node run.mjs ledger --ledger 我的台账.xlsx a.json          # 换台账文件
```

**不追加的后果**：这次的数据只存在于当次报告里，下次抓完无法和它对比。

## 批次号

由 JSON 里的 `scrapedAt` 生成，形如 `B20261109_065426`。
同一份 JSON 重复追加会被跳过（打印「批次已存在」），所以重复运行是安全的。

## 两个 sheet

| Sheet | 一行代表 | 关键列 |
|---|---|---|
| **批次汇总** | 一次抓取批次 | 批次号、抓取时间、视频数、评价数、达标数、达标率、复检重合率、深度不足数、来源文件 |
| **达标评价** | 一条达标评价 | 批次号、视频层次、该档阈值、视频ID、视频点赞、评价点赞、内容、评价者、地区、cid |

## 台账能回答什么

- **数据稳不稳**：同一视频不同批次的达标评价数变化 → 是不是抓取不稳
- **关键词质量变化**：某词历次抓取的达标率趋势
- **跨批次去重**：按 cid 查某条评价是否在多个批次都被抓到

## 与 Excel 的区别

| 文件 | 每次运行 | 用途 |
|---|---|---|
| `抖音抓取结果_<日期>.xlsx` | **覆盖**（当次快照） | 看当前这批数据 |
| `抓取台账.xlsx` | **追加**（累积档案） | 跨批次对比、历史追溯 |

两个都要生成：前者看当期，后者存历史。
