# 故障排查

## 按现象查

| 现象 | 退出码 | 原因 | 处置 |
|---|---|---|---|
| 搜索结果 0 条，标题是验证码页 | 4 | 直接 navigate 到搜索页 | 确认走「首页预热 + 站内跳转」 |
| 搜索结果 <30 条，标题正常 | 3 | 静默限流 / 登录态失效 | 先查 cookie（见下），再换词或等 10 分钟 |
| 评论 0 条，commentErr 有值 | 3/4 | 评论接口风控 | 冷却重跑，加大页数无效 |
| 深度判定 TOO_CLOSE_TO_EDGE | 3 | TOP N 贴着抓取边界 | 加大 --pages 重跑 |
| 深度判定 UNKNOWN_HAS_MORE | 3 | 抓取状态字段丢失 | 重跑；连续出现查 dy_scrape 版本 |
| 未找到 Chrome | 1 | 浏览器路径不对 | 设 DY_CHROME 环境变量 |
| 视频全部失败 | 4 | ID 错 / 被删 / 私密 | 核对 videoId |
| xlsx / ledger 报错 | 4 | 缺 Python 或 openpyxl | `pip install openpyxl` |

## 按检查项查

```bash
node run.mjs health      # 环境：语法/单测/浏览器/登录态/冷却账本
node run.mjs audit       # 方案：脚本完整性/参数一致性/调用链/路径解耦
```

## 跨天重抓注意

- 点赞是实时增长的，对比数据要标注抓取时刻
- 新评论涌入会改变排序，同一视频不同天的 TOP10 不完全可比
- 评论总数会变小（被删/折叠），不是抓漏

## 数据口径备忘

| 概念 | 定义 |
|---|---|
| 评价条数 | 抓到的条数（≤ 档位上限），不是平台评论总数 |
| 达标数 | 达到该视频档位门槛的条数 |
| 覆盖率 | 抓到 ÷ 平台评论总数，实测约 1.2% |
| 占赞比 | 单条评价点赞 ÷ 该视频点赞 |

## 长跑与达人层（2.0 新增）

| 现象 | 原因 | 处置 |
|---|---|---|
| 跑到第 40–50 个开始连片失败 | profile 有效体积过高，Chrome 假死（报错像风控） | `account --sweep-every 10`（默认已开）；或先用 `DY_PROFILE_RESET=1` 重建 |
| 明明登录了却报「未登录」 | 预检只认老路径 `Default/Cookies` | 2.0 已同时认 `Default/Network/Cookies`；旧版请升级 |
| 达人抓 0 条，正文 <1200 字 | 账号失效 / 被降级 | 换账号复验；`source=none` 且 `apiHits=0` 就是这种情况 |
| 达人只抓到 20 条且 `hasMore=1` | 首屏上限，不是失败 | 21 条已覆盖 ≥15 天的占 100%，够用 |
| 图文作品抓不到评论 | 用了 `/video/` 地址 | 2.0 会自动回退 `/note/`；外部传 ID 时也一样 |
| `--par 3` 下偶发「页面未加载完成」 | 三条并行同时渲染、机器吃紧 | 降到 `--par 2`；仍是 0 条再怀疑风控 |
| 关闭终端后 Chrome 还在 | 复用了别人启动的实例，不归本进程清理 | 正常设计；`health` 能看到端口占用，手工关即可 |

### 搜索 0 响应：先查登录态，别急着怪风控

页面标题正常、DOM 空、`search` 接口一个不发时，先确认 cookie：

```
passport_csrf_token  ← 只有这个 = 未登录（搜索页只渲染壳，不发数据接口）
sessionid / sid_tt   ← 有这两个才是真登录
```

只看到 `passport_csrf_token` 就执行 `node run.mjs login` 重新扫码，不用等冷却。
